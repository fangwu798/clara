# 自定义工作流目录

这里存放「模型生成 / 用户自写」的工作流定义，与随应用发布的内置流程（`config/workflow/*.yml`）分开管理。

- 放置方式：文件名用 `<工作流标识>.yml`（如 `export_daily_report.yml`），标识写在文件内的 `workflowId`，
  建议与文件名保持一致。
- 生效方式：**无需重启**。Clara 启动时加载本目录；运行期每次调用工作流前按文件签名（修改时间 / 大小）
  自动刷新定义，因此「会话里刚生成 → 立刻可按标识运行」。
- 推荐入口：直接对 Clara 说「帮我做一个……的工作流」即可，`author_custom_workflow` 会起草、自检并发布到本目录；
  也可以让模型调用内置工具 `publish_workflow`（先校验、后落盘，报错含节点 id），或者自己手写文件。
- 命名约束：`workflowId` 只允许字母 / 数字 / 下划线 / 中划线；不得与内置流程重名，重名会被拒绝发布 / 加载。
- 写坏了怎么办：某个文件解析失败不会影响其它工作流，但该文件不会被加载；`run_workflow` 的报错里会带上
  加载失败的原因，按提示修正后自动重试。
- 编写规范：节点类型、变量占位、TOOL / AGENT 节点字段的完整说明见 `config/skill/prompt/workflow_author.json`。

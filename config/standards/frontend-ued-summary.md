# 前端设计规范（Honeycomb UED 摘要）

> 用途：作为「前端开发规范」注入模型提示词，指导生成《需求与技术方案》《开发计划》中的前端部分（页面结构、组件选型、布局、交互、无障碍）。以下均为规范性取值，可直接对照执行。
> 来源：`docs/honeycomb-ued-full.html`（honeycomb 设计体系快照 V1.0）。设计基线：桌面 1440px，主色 #266EFF。

## A. UED 设计原则

### A.1 核心价值观
一致（跨系统交互一致性有效融合）、灵活（模式规则具弹性，适配独特业务）、高效（减少认知成本，提升交互确定性）、开放（公开进行中组件，共建完善）。

### A.2 六项设计原则（Frame / Intimacy / Align / Repeat / Contrast / Feedback）
| 原则 | 说明 | 落地示例 |
| --- | --- | --- |
| 框架 Frame | 先定平台层级与页面骨架，再组织业务模块 | 顶栏、侧栏、工作区、卡片区、大屏 |
| 亲密性 Intimacy | 相关信息靠近，无关信息用更大间距分组 | 表单项、指标组、工具栏与表格 |
| 对齐 Align | 标题/标签/数字金额遵循稳定对齐线 | 标签右对齐、金额右对齐、操作列对齐 |
| 重复 Repeat | 同类组件、文案格式、图标排版保持一致 | 卡片列表、状态标签、行操作 |
| 对比 Contrast | 用字号、字重、颜色、留白表达主次与状态 | 主按钮、关键指标、异常信息 |
| 即时反馈 Feedback | 操作后及时显示成功/失败/校验/刷新状态 | Message、Alert、表单校验、Loading |

### A.3 六条落地要点
- **产品气质**：克制、清晰、稳定；信息密度优先于装饰；颜色承担状态与信息编码职责。**复用驱动效率**：标准组件、页面模板、业务组件减少重复设计与开发。
- **组件九态矩阵**：Default / Hover / Focus / Active / Selected / Disabled / Loading / Error / Empty。**数据格式与文案**：空值 `--`、0 为有效值；状态以文本为主颜色为辅；按钮「动词+对象」；错误先结果后原因。
- **无障碍**：对比度 ≥ 4.5:1；全键盘可用；focus-visible 清晰；状态不只靠颜色。**AI 交互按生命周期验收**：开始/提示/执行/结果/结束，覆盖上传、处理中、转人工等阶段。

## B. 基础样式规范（Design Tokens 与基础组件样式）

### B.1 色彩
**品牌与交互色（`--hc-primary` 系列）**
- primary #266EFF（主色/主按钮/链接/选中）、hover #518BFF、active #2263E6（按下；正文级蓝字对比度 5.26:1）。
- 浅色阶：primary-1 #EBF2FF（选中底/信息底）· 2 #CCDDFF · 3 #A8C5FF · 4 #84ADFF（焦点环）。
- 深色阶：5 #6397FF · 6 #4583FF · 8 #175BE5 · 9 #044AD6 · 10 #003EBD。

- 默认系统主题「景泰蓝」渐变 **#266EFF → #4A85F6 → #55B8FF**。
- 业务界面通过语义 Token 引用，不在组件中直接绑定某一档原始色值。

**功能色**
- info 信息/链接 #266EFF · success 成功 #1CC78D · warning 警示 #FF9902 · danger 危险 #FF4C4C。
- 约束：info 不与普通正文仅靠颜色区分；success 配合图标或文字；warning 不用于普通装饰；danger 删除确认必须同时写明后果。旧 Element 功能色（#13CE66 / #F7BA2A / #FF4949）新页面应迁移，避免同屏混用。

**中性色**
- 文本：text-1 #333333（12.63:1）· text-2 #666666（5.74:1）· text-3 #999999（2.85:1，仅辅助，勿承载重要信息）。
- 结构色：icon/disabled #C5C5C5 · border #DDDDDD · divider #EAEAEA · fill-hover #F5F5F5 · nav-bg #F8F8F8 · table-head #FBFBFB · surface #FFFFFF。

**可视化分类色序列（顺序稳定，同指标跨页面同色）**：#FF5001 → #FF9102 → #04B77D → #3397FF → #6B4EFF。状态数据沿用成功/警示/错误功能色语义。

### B.2 字体排版
- **字体族**：`"Helvetica Neue", Helvetica, Arial, "PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`。Mac 中文优先 PingFang SC，Windows 优先 Microsoft YaHei；英文/数字优先 Helvetica / Arial。不依赖用户未必安装的定制字体。
- **字重**：常规只用 **400 Regular、500 Medium**；英文强调可用 600 Semibold。
- **字阶与行高**（业务系统通常只用 3–5 个字阶）：
  - 20 / 28px（500–600）特殊提示、关键大标题；16 / 24px（500）详情页标题。
  - 14 / 22px（400–500）导航、Tabs、分组标题（推荐基准）。
  - 13 / 22px（400）正文、表格与表单主体；12 / 22px（400）辅助说明、时间、次级元数据。

- 文档标题 H1–H6：**36 / 26 / 20 / 18 / 16 / 14px，字重 500**。

### B.3 间距与栅格
- **间距刻度（4px 基准）**：space-1=4、space-2=8、space-3=12、space-4=16、space-6=24、space-8=32（px）。常用 **8 / 12 / 16 / 24 / 32px**；特殊模块可用其他 4px 倍数（如 20px），禁用无规律值。
- **PC 栅格**：**24 栅格**；内容区 **1208px**（1440 基准）；页边距 **12px**；水槽 **12px**。
- **推荐画板 1440 × 820px**；兼容 1280 / 1366 / 1600 / 1920。
- **断点收敛**：compact < 720、medium 720–1199、wide ≥ 1200。移动端不是桌面等比缩小，需重定信息优先级与触控热区。

### B.4 尺寸 · 圆角 · 边框 · 阴影
| 项目 | 规范值 |
| --- | --- |
| 输入框高度 | 大 42px / 默认 36px / 小 32px / 迷你 28px；默认输入框 36px 高、12px 水平内边距、3px 圆角、边框 #DDD；Focus 边框 #266EFF；Placeholder 不代替字段名 |
| 控件圆角（按钮/输入框/文本域） | 3px；对话框圆角 4px |
| 单选 / 复选 | 16 × 16px；Switch 46 × 20px、圆角 10px（默认 #D3D8DD / 选中 #34A6F8） |
| 基础边框 / 阴影 | 1px solid #DDDDDD；对话框阴影 0 2px 4px rgba(0,0,0,.2) |
| 动效时长 | 200–300ms（边框/背景/侧栏/浮层） |

### B.5 按钮 Button
- **类型**：主按钮 primary、次按钮（白底 #DDD 边框）、虚线按钮、文字按钮（link）、图标按钮、危险操作。
- **状态色**：Default #266EFF、Hover #518BFF、Active #2263E6；危险 #FF4C4C；禁用 底 #F5F5F5 / 文本弱化 / `not-allowed`。
- **焦点**：`outline: 2px solid #84ADFF; outline-offset: 2px;`。

| 尺寸 | 内边距（垂直 × 水平） | 最小宽 | 字号 |
| --- | --- | --- | --- |
| 大 | 11px × 19px | — | 14px |
| 默认 | 8px × 15px | 100px | 13px |
| 小 | 8px × 9px | — | 12px |
| 迷你 | 7px × 15px | — | 11px |

- **规则**：同一操作区只设一个主按钮；取消在左、确定在右，位置跨页面一致；图标按钮必须有 Tooltip；加载时保留原宽度；禁用/加载不可重复触发；危险按钮写具体动作（如「删除合同」），不写模糊「确定」。

### B.6 图标与通用状态（九态）
- **图标**：基于关键线和网格绘制，视觉重心居中；同一组图标线宽、圆角、透视一致；常规线性图标默认 **#999999**、禁用 **#C5C5C5**，选中/可操作状态用主题色；图标与文字并存时间距 **4–8px**；不混用线性与面性风格；图标按钮用熟悉符号（搜索/刷新/下载/更多/关闭）并提供 Tooltip / 可访问名称。
- **九态矩阵（每个可交互组件必备）**：
  - Default 可识别、可操作，层级符合任务；Hover 改变边框/文字/背景，不引起布局位移。
  - Focus 清晰焦点环（不被 `outline:none` 吞掉）；Active 用 #2263E6 更深状态色反馈按下；Selected 主题色/选中图标/浅主题背景。
  - Disabled #F5F5F5 背景、弱化文本、`not-allowed`；Loading 保持组件尺寸并阻止重复提交。
  - Error 错误色 + 图标 + 可执行文案，焦点移到首错；Empty 区分首次/筛选/失败/无权限并给单一主行动。

## C. 组件全样式（组件名 + 关键规格 / 使用约束）

### C.1 通用 / 导航
| 组件 | 关键设计要点 / 规格 |
| --- | --- |
| Button 按钮 | 尺寸与类型见 B.5；图标按钮需 Tooltip |
| Icon 图标 | 线性默认 #999、16px，禁用 #C5C5C5 |
| Toolbar 工具栏 | 批量操作仅选中后启用并显示选中数；导入任务显示校验、进度与结果下载 |
| Steps 步骤条 | 表达有先后依赖的任务；显示完成/当前/等待/错误；返回时保留已填数据 |
| Pagination 分页 | 切页后焦点/滚动回数据区起点；默认右下，左侧可展示总数 |
| Menu 菜单 | 表达稳定信息架构；当前项主题色 + 浅色背景；允许收起 |
| Breadcrumb 面包屑 | 显示层级位置；末级不可点击；标题不与末级面包屑重复堆叠 |
| Tabs 选项卡 | 平级视图，不用 Tabs 代替步骤流程；默认 14px、标签高 49px、激活底线 3px |
| Tree 树 | 节点选择与展开必须使用不同热区，避免误操作 |
| Search 搜索 | 简单筛选可立即生效；多条件组合用「查询」；规则不得在同页混用 |
| Iframe 嵌入 | 容器形态，用于嵌入第三方页面/报表/地图 |

### C.2 数据录入
| 组件 | 关键设计要点 / 规格 |
| --- | --- |
| Textbox 文本框 | Label 简短稳定，必填标记紧邻 Label；Placeholder 仅做格式提示，不代替字段名 |
| Select 下拉 | 选项超过 7–10 项提供搜索；层级选项改用 TreeSelect / Cascader |
| TreeSelect / Cascader | 层级/多级选择；跨实体复杂选择用弹出选择器 |
| AutoComplete | 联想补全，命中关键词高亮；保留用户已输入内容 |
| DatePicker / TimePicker / RangePicker | 遵循数据格式规则；范围输入必须明确起止与单位 |
| Spinner 数字输入 | 步进数值输入；明确单位与小数位 |
| Radio 单选 | 互斥且选项通常 ≤5–7 项；默认值时选安全、常用项 |
| Checkbox 复选 | 允许零到多项；全选使用 indeterminate 表达部分选中 |
| Switch 开关 | 设置立即生效时使用；需提交或有严重后果时改用 Checkbox + 保存 |
| Upload 上传 | 明确文件类型、数量、单文件大小；逐项显示上传中/成功/失败与重试 |
| Richtext 富文本 | 工具栏只暴露业务需要的格式；只读与禁用状态必须区分 |
| Form 表单 | 简单表单优先单列，高频短字段可双列；组间距大于组内间距；未保存离开提醒 |
| 业务录入 | AddressSelect（行政区划联动到街道）、LookPopup / PopupSelection（跨实体弹出回填）、ProjectSelect（项目上下文） |

### C.3 数据展示
| 组件 | 关键设计要点 / 规格 |
| --- | --- |
| Grid 表格 | 文本左对齐、日期统一、数字金额右对齐、状态全表一致；行操作只留 1–3 个高频；Hover 与选中需明确区分；表头背景 #FBFBFB，字号 12px |
| Tag 标签 | 高 22px、圆角 4px、字号 12px；短状态或分类，不承载长句；相同语义跨页面同色 |
| InfoProfile 简档 | 对象摘要，可组合状态、关键指标与工具栏；详情信息移入详情区 |
| Card 卡片 | 独立可重复的信息对象；不将普通页面分区全部卡片化；标题/摘要/指标/状态/操作顺序固定 |
| List 列表 | 列表项保持标题、摘要、指标、状态、操作的固定顺序与高度策略 |
| Brieffile | 文件条目逐项展示；提供预览、下载与来源信息 |
| Percentage 百分比 | 进度展示；用状态色区分正常/警告/危险（进度条高 8px、圆角 4px） |
| CriticalPath 关键路径 | 当前节点、阻塞、逾期、完成必须可区分；过程详情提供责任人、时间、输入输出与异常原因 |

### C.4 反馈与浮层
| 组件 | 关键设计要点 / 规格 |
| --- | --- |
| Alert 警示 | 页面内持续可见的重要信息；不用于普通成功提示 |
| Message 消息 | 轻量、自动消失的操作结果；不承载需要决策或长文本 |
| Notification 通知 | 跨页面、较完整的异步结果 |
| Dialog 对话框 | 需聚焦的确认或短任务；标题栏 48px、正文内边距 20px；焦点管理，关闭后归还触发点 |
| Popconfirm 确认 | 后果明确的单步确认；高风险/复杂影响用 Dialog |
| Popover 气泡 | 依附触发元素的补充信息 / 轻操作 |
| Empty 空状态 | 区分首次无数据/筛选无结果/加载失败/无权限，并给出对应单一主行动 |

### C.5 业务组件
- **Checklist / ClassSelection / PopupSelection**：配置型勾选、分类选择、弹出选择；明确已选数量与可选项。
- **Transfer 穿梭框**：两端数量实时更新；选项过多提供搜索。
- **Layout 布局**：页面骨架（上左右 / 上下）；保持固定导航 + 24 栅格内容区。
- 所有可交互组件必备九态（见 B.6）。

## E. 信息架构与全局框架

### E.1 产品气质
克制、清晰、稳定；面向高频、复杂、长时间使用的企业业务；信息密度优先，颜色首先承担状态与信息编码职责，不做装饰；通过标准组件/页面模板/业务组件标准化提效；桌面基线 1440px（兼容 1280/1366/1600/1920）。

### E.2 一级导航
一级导航仅保留当前工作域；页面内导航用左侧分组 + 右侧锚点目录。文档标题 H1–H6 字号 36/26/20/18/16/14px、字重 500。

### E.3 五段式业务框架
1. **顶部应用栏**：品牌、应用/项目上下文、全局搜索、帮助、通知、用户菜单。
2. **左侧导航**：一级业务模块固定；允许收起；当前项用主题色 + 浅色背景突出。
3. **内容头部**：面包屑、页面标题、状态、主操作；避免同时出现多个等权主按钮。
4. **内容主体**：筛选区、工具栏、数据区、分页区；复杂任务用 Tabs / 步骤条拆分。
5. **临时任务**：轻量确认 Popconfirm / 聚焦任务 Dialog / 保留上下文的复杂编辑 Drawer。

### E.4 布局度量（文档站 / 原站 CSS 实测）
| 项目 | 规范值 |
| --- | --- |
| 顶栏高度 | 60px，白底、底部 1px 分隔线 |
| 一级导航链接 | 14px / 400，行高约 56px，激活与 Hover 用 3px 底线 |
| 设计文档侧栏 | 220px |
| 正文最大宽度 | 1240px（主区 0 60px 内边距） |
| 文档标题 H1–H6 | 36 / 26 / 20 / 18 / 16 / 14px，字重 500 |
| 窄屏断点 | 侧栏切换为抽屉式 |

## F. 数据 · 文案 · 反馈选型

### F.1 数据格式
1. **数值**：一致的小数位与千分位；金额同时明确币种。
2. **日期**：同页统一 `YYYY-MM-DD`；需要时显示时间与时区。
3. **百分比**：不得混用 `0.25` 与 `25%` 两种写法。
4. **空值 / 零值**：空值用 `--`；**0 是有效数据，不得显示为空**。
5. **脱敏**：按数据等级全量或部分脱敏；查看原文需授权并记录审计。
6. **状态**：文本为主、颜色为辅；状态名用业务结果，不用内部代码。
7. **Loading**：骨架屏适合稳定布局；Spinner 适合局部短等待；长任务显示阶段或进度。

### F.2 文案规则
1. **一致**：同一动作只用一个名称（统一「保存」，不混用 提交/确认）。
2. **易读**：先结果后原因，短句、主动语态，避免内部术语与重复敬语。
3. **按钮**：动词或「动词 + 对象」（新建合同、重新上传）。
4. **错误**：说明问题与修复方法（「结束日期不能早于开始日期，请重新选择」）。
5. **标点**：中文用全角标点；英文产品名/数字/单位按团队词典统一。
6. **命名**：设计图层/组件/埋点/代码命名可互相映射，禁止 `copy 2` 等无语义名。

### F.3 空状态文案矩阵
| 场景 | 标题 | 行动 |
| --- | --- | --- |
| 首次无数据 | 暂无合同 | 新建合同（有权限时） |
| 筛选无结果 | 未找到符合条件的合同 | 清空筛选条件 |
| 加载失败 | 合同加载失败 | 重新加载 + 错误编号 |
| 无权限 | 暂无合同查看权限 | 申请权限 或 返回 |

### F.4 反馈与浮层选型
| 组件 | 适用 | 不适用 |
| --- | --- | --- |
| Message | 轻量、自动消失的操作结果 | 需要用户决策或阅读长文本 |
| Notification | 跨页面、较完整的异步结果 | 当前字段校验 |
| Alert | 页面内持续可见的重要信息 | 普通成功提示 |
| Popover | 依附触发元素的补充信息 / 轻操作 | 长表单或关键确认 |
| Popconfirm | 后果明确的单步确认 | 高风险、复杂影响说明 |
| Dialog | 需要聚焦的确认或短任务 | 超长、多区复杂编辑 |
| Drawer | 保留当前上下文的详情或复杂编辑 | 极简确认 |
| Loading | 数据或操作处理中 | 无法估算且长期阻塞（应补进度/说明） |

## G. AI 交互专项

### G.1 对话生命周期
八个阶段 + 错误分支：**① 触发入口 → ② 开场与能力预期 → ③ 用户输入 → ④ 理解/澄清 → ⑤ 执行过程 → ⑥ 结果展示 → ⑦ 结果确认/继续处理 → ⑧ 结束**；异常分支 **错误 / 不支持 / 转人工**。

- **开始**：热情但简短，明确能做什么，由用户主导。
- **提示**：给建议而非命令，无匹配项时提供改写或替代路径。
- **执行**：侧栏辅助适合保留业务上下文；静默处理只用于低风险、可撤销动作。
- **结果**：按结果结构选消息卡/表单卡/检查卡，显示置信度或证据时不制造虚假精确性。
- **结束**：支持完成、放弃、不支持与系统问题；保存上下文并允许重新开始。

### G.2 AI 组件清单
| 分类 | 组件与要求 |
| --- | --- |
| 通用与开场 | Button / Bubble（操作明确、角色可辨）；Conversations（历史可管理）；Welcome / Prompts（说明能力边界，示例可直接触发） |
| 输入 | Skill Catalog、Sender、Attachment、Image、Screenshot —— 格式/大小提示、上传状态、发送可取消 |
| 输出 | Text、Image、Code、Table、Form、Attachment —— 来源、复制/下载、结构化编辑与确认 |
| 反馈 | Exception Notification、Message Hint —— 可恢复错误与下一步行动 |

### G.3 错误分级与恢复动作
| 错误类型 | 恢复动作 |
| --- | --- |
| 无法解析 | 引导重述或给出示例 |
| 输入无效 | 指出具体无效字段并给修正方式 |
| 能力不支持 | 说明边界并提供替代路径 |
| 系统异常 | 友好报错 + 重试 / 转人工 |

AI 业务案例覆盖：新增督办、生成价格方案、合同审查、价格审查、明源知识库、在线客服。设计评审必须以完整生命周期验收，而非一张对话截图。

## I. 无障碍与交付验收

### I.1 无障碍清单
1. **对比度**：正文与背景至少 4.5:1，大字 3:1；状态不能只依赖颜色。
2. **键盘**：全部功能可键盘操作，焦点顺序与视觉一致；focus-visible 清晰可见。
3. **可访问名称**：图标按钮/输入框/上传/图表/浮层提供名称；装饰图片用空 alt。
4. **语义**：表格正确表头关联；排序用 `aria-sort`；错误字段用 `aria-describedby`。
5. **动效**：尊重 `prefers-reduced-motion`；自动轮播可暂停；消息停留时间允许阅读。
6. **缩放**：页面缩放 200% 不丢内容或操作；320px 宽度不出现无意义重叠。

### I.2 主色 / 状态色对比度实测（浅色底 #FFFFFF）
| 色值 | 对比度 | 结论 |
| --- | --- | --- |
| 主色 #266EFF（白字） | 4.41:1 | 大字号/加粗可用；正文级建议用 #2263E6（5.26:1） |
| Hover #518BFF（白字） | 3.24:1 | 仅大字号 / 图标场景 |
| success #1CC78D | 2.19:1 | 仅作非文字状态色，需配合图标/文字 |
| warning #FF9902 | 2.14:1 | 仅作警示状态色，避免承载文字信息 |
| danger #FF4C4C | 3.29:1 | 正文级文字建议加深色变体 |
| 正文 #333333 | 12.63:1 | 达标 ✓ |
| 次要 #666666 | 5.74:1 | 达标 ✓ |
| 说明 #999999 | 2.85:1 | 仅作辅助装饰，重要信息勿用 |

### I.3 设计交付物
1. **页面流与状态流**：正常/空/加载/错误/无权限/边界数据。
2. **Token 高保真稿**：使用语义化 Token，不散落无命名色值和间距。
3. **变体与交互说明**：触发/反馈/焦点/关闭/撤销/超时。
4. **响应式稿**：至少覆盖 compact、medium、wide 三档关键变化。
5. **内容清单**：标题/字段/按钮/状态/错误和空状态文案。

### I.4 前端验收 checklist（逐项自检）
- [ ] **统一体系**：使用统一色彩、字号、字重、行高和 4 点间距体系。
- [ ] **多宽适配**：1440 基准正确，1280 / 1366 / 1600 / 1920 无遮挡或溢出。
- [ ] **状态完整**：所有交互组件具备 Hover / Focus / Active / Disabled / Loading / Error 状态。
- [ ] **表格数据**：数字右对齐，空值、零值、超长文本与大数据量显示正确。
- [ ] **表单可用**：键盘可用、错误可定位、重复提交被阻止、未保存离开有提醒。
- [ ] **弹窗焦点**：焦点管理正确，关闭后焦点回到触发元素。
- [ ] **状态可恢复**：空、错、无权限、断网和超时状态均可恢复。
- [ ] **无障碍通过**：颜色对比度、可访问名称、语义标签和减少动效通过检查。
- [ ] **缩放无重叠**：浏览器缩放 200% 及 320px 宽度下内容不重叠。

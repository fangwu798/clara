UED 设计原则

Design Principles — 平铺
一致
跨系统交互一致性有效融合
灵活
模式规则具弹性，适配独特业务
高效
减少认知成本，提升交互确定性
开放
公开进行中组件，共建完善
▦
框架 Frame
先确定平台层级和页面骨架，再组织业务模块。
应用：顶栏、侧栏、工作区、卡片区、大屏
◫
亲密性 Intimacy
相关信息靠近，无关信息用更大间距分组隔开。
应用：表单项、指标组、工具栏与表格
⇶
对齐 Align
标题、标签、数字金额遵循稳定对齐线。
应用：标签右对齐、金额右对齐、操作列对齐
◍
重复 Repeat
同类组件、文案格式和图标排版保持一致。
应用：卡片列表、状态标签、行操作
◐
对比 Contrast
用字号、字重、颜色、留白表达主次与状态。
应用：主按钮、关键指标、异常信息
↻
即时反馈 Feedback
操作后及时显示成功、失败、校验或刷新状态。
应用：Message、Alert、表单校验、Loading
1
产品气质：克制、清晰、稳定信息密度优先于装饰；颜色承担状态与信息编码职责。
2
复用驱动效率标准组件、页面模板、业务组件减少重复设计与开发。
3
组件九态矩阵Default / Hover / Focus / Active / Selected / Disabled / Loading / Error / Empty。
4
数据格式与文案空值 --、0 有效；状态文本为主颜色为辅；按钮“动词+对象”；错误先结果后原因。
5
无障碍对比度≥4.5:1；全键盘可用；focus-visible 清晰；状态不只靠颜色。
6
AI 交互按生命周期验收开始/提示/执行/结果/结束，覆盖上传、处理中、转人工等阶段。

组件使用要点速查 §4 按分类速查 · 设计 / 开发对照
组件关键设计要点
通用 / 导航
Toolbar批量操作仅在选中后启用并显示选中数；导入任务显示校验、进度与结果下载
Steps表达有先后依赖的任务；显示完成 / 当前 / 等待 / 错误；允许返回时保留已填数据
Pagination数据导航；切页后焦点 / 滚动回到数据区起点；分页默认右下，左侧可展示总数
Menu表达稳定信息架构；当前项主题色 + 浅色背景突出；允许收起
Breadcrumb显示层级位置；末级不可点击；标题不与末级面包屑重复堆叠
Tabs平级视图，不用 Tabs 代替步骤流程；默认 14px、标签高 49px、激活底线 3px
Tree层级浏览；节点选择与展开必须使用不同热区，避免误操作
Search简单筛选可立即生效；多条件组合用「查询」；规则不得在同页混用
数据录入
TextboxLabel 简短稳定，必填标记紧邻 Label；Placeholder 仅做格式提示，不代替字段名
Select选项超过 7–10 项提供搜索；层级选项改用 TreeSelect / Cascader
TreeSelect / Cascader层级 / 多级选择；跨实体复杂选择使用弹出选择器
AutoComplete联想补全，命中关键词高亮；保留用户已输入内容
DatePicker / TimePicker / RangePicker日期金额等遵循数据格式规则；范围输入必须明确起止与单位
Spinner步进数值输入；明确单位与小数位
Radio互斥且选项通常 ≤5–7 项；必须有默认值时选安全、常用项
Checkbox允许零到多项；全选使用 indeterminate 表达部分选中
Switch设置立即生效时使用；需提交或有严重后果时改用 Checkbox + 保存
Upload明确文件类型、数量、单文件大小；逐项显示上传中 / 成功 / 失败与重试
Richtext工具栏只暴露业务需要的格式；只读与禁用状态必须区分
Form简单表单优先单列，高频短字段可双列；组间距大于组内间距；未保存离开提醒
数据展示
Grid 表格文本左对齐、日期统一、数字金额右对齐、状态全表一致；行操作只留 1–3 个高频；Hover / 选中需明确区分
Tag短状态或分类，不承载长句；相同语义跨页面保持相同颜色
InfoProfile对象摘要，可组合状态、关键指标与工具栏；详情信息移入详情区
Card独立可重复的信息对象；不将普通页面分区全部卡片化；标题/摘要/指标/状态/操作顺序固定
List列表项保持标题、摘要、指标、状态、操作的固定顺序与高度策略
Brieffile文件条目逐项展示；提供预览、下载与来源信息
Percentage进度展示；用状态色区分正常 / 警告 / 危险
CriticalPath当前节点、阻塞、逾期和完成必须可区分；过程详情提供责任人、时间、输入输出与异常原因
反馈与浮层
Alert页面内持续可见的重要信息；不用于普通成功提示
Message轻量、自动消失的操作结果；不承载需要决策或长文本的内容
Notification跨页面、较完整的异步结果
Dialog需聚焦的确认或短任务；标题栏 48px、正文内边距 20px；焦点管理，关闭后归还触发点
Popconfirm后果明确的单步确认；高风险 / 复杂影响用 Dialog
Popover依附触发元素的补充信息 / 轻操作
Empty区分首次无数据 / 筛选无结果 / 加载失败 / 无权限，并给出对应单一主行动
业务组件
Checklist / ClassSelection / PopupSelection配置型勾选、分类选择、弹出选择；明确已选数量与可选项
Transfer穿梭移动，两端数量实时更新；选项过多提供搜索
Layout页面骨架（上左右 / 上下）；保持固定导航 + 24 栅格内容区
每个可交互组件必备 9 态：Default / Hover / Focus / Active / Selected / Disabled / Loading / Error / Empty（详见基础样式 · 图标与通用状态）。

数据 · 文案 · 反馈选型

Content & Feedback — 数据格式 / 文案 / 空状态 / 浮层选择
数据与文案规范 §6
数据格式 §6.1
1
数值一致的小数位与千分位；金额同时明确币种
2
日期同页统一 YYYY-MM-DD；需要时显示时间与时区
3
百分比不得混用 0.25 与 25% 两种写法
4
空值 / 零值空值用 --；0 是有效数据，不得显示为空
5
脱敏按数据等级全量或部分脱敏；查看原文需授权并记录审计
6
状态文本为主、颜色为辅；状态名用业务结果，不用内部代码
7
Loading骨架屏适合稳定布局；Spinner 适合局部短等待；长任务显示阶段或进度
文案规则 §6.2
1
一致同一动作只用一个名称（统一「保存」，不混用提交/确认）
2
易读先结果后原因，短句、主动语态，避免内部术语与重复敬语
3
按钮动词或「动词 + 对象」：新建合同、重新上传
4
错误说明问题与修复方法（「结束日期不能早于开始日期，请重新选择」）
5
标点中文用全角标点；英文产品名 / 数字 / 单位按团队词典统一
6
命名设计图层 / 组件 / 埋点 / 代码命名可互相映射，禁止 copy 2 等无语义名
空状态文案矩阵 §10.3
场景标题行动
首次无数据暂无合同新建合同（有权限时）
筛选无结果未找到符合条件的合同清空筛选条件
加载失败合同加载失败重新加载 + 错误编号
无权限暂无合同查看权限申请权限 或 返回
Empty 区分首次 / 筛选 / 失败 / 无权限，并提供对应单一主行动。
反馈与浮层选型 §4.6 什么时候用哪个
组件适用不适用
Message轻量、自动消失的操作结果需要用户决策或阅读长文本
Notification跨页面、较完整的异步结果当前字段校验
Alert页面内持续可见的重要信息普通成功提示
Popover依附触发元素的补充信息 / 轻操作长表单或关键确认
Popconfirm后果明确的单步确认高风险、复杂影响说明
Dialog需要聚焦的确认或短任务超长、多区复杂编辑
Drawer保留当前上下文的详情或复杂编辑极简确认
Loading数据或操作处理中无法估算且长期阻塞（应补进度/说明）

Visualization & Terminal — 图表选型 / 主题色板 / 终端布局
图表选型矩阵 §8.2
目标推荐图表避免
趋势折线、面积类别过多的多折线
类别比较柱状、条形难比较角度的饼图
构成占比饼 / 环（少量分类）、百分比环大量或接近比例的扇区
多维画像雷达（维度有限）量纲未标准化
阶段转化漏斗 / 金字塔无顺序关系的分类
单指标达成仪表盘 / 进度多个仪表盘堆叠
所有图表页统一包含：介绍、应用场景、使用原则、标准样式和变体。轴、图例、Tooltip、单位、空数据、异常值与数据更新时间必须完整设计。
极简白主题 12 色序列
普通报表与 PC 工作台采用「极简白」主题。分类色顺序稳定，同一指标跨页面保持同色。
科技蓝主题 12 色序列 · 深色大屏
深色大屏采用「科技蓝」主题（底色约 #120A36、面板约 #0F1450）。深色主题必须重新核验文字、网格线和 Tooltip 对比度，不能直接反转浅色主题。

终端画板 / 栅格布局规则

移动750 × 1334 设计基准列表 / 卡片 / 平铺三类；减少同时展示维度，详情下钻

无障碍与可用性 §9
无障碍清单
1
对比度正文与背景至少 4.5:1，大字 3:1；状态不能只依赖颜色
2
键盘全部功能可键盘操作，焦点顺序与视觉一致；focus-visible 清晰可见
3
可访问名称图标按钮 / 输入框 / 上传 / 图表 / 浮层提供名称；装饰图片用空 alt
4
语义表格正确表头关联；排序用 aria-sort；错误字段用 aria-describedby
5
动效尊重 prefers-reduced-motion；自动轮播可暂停；消息停留时间允许阅读
6
缩放页面缩放 200% 不丢内容或操作；320px 宽度不出现无意义重叠
